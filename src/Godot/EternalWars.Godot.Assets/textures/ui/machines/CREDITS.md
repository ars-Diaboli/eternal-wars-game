# War machine icons

Painted war machine icons with transparency (160 × 160), generated for this project by the owner (2026-11-16, replaced 2026-11-24 in a three-quarter view, set 7) as an icon
sheet and cut into one file per machine (prompts in `docs/content/prompts/icon-prompts.md`). Loaded through `EternalWars.Godot.UI.HeroIcons`; a
machine without a file shows its name alone.

| File | Used for |
|---|---|
| ballista.png / catapult.png / healing_tent.png / ammo_cart.png | the hero screen's war machines; the blacksmith, the war machine factory and the hero exchange buttons |

Not drawn yet: `cannon.png`, `glaivethrower.png` (the offensive machines of the towns that field them).
