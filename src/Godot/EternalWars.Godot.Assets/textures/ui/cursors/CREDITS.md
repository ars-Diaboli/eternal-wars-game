# Cursors

Mouse cursors, 64 × 64 with transparency (shown at 43 × 43; the pointer, busy and blocked ones at 32 × 32), in pale satin aluminium
(ADR-312), generated for this project by the owner (2026-11-25) from sets 1–3 and 5–7 of
[cursor-prompts.md](../../../../../../docs/content/prompts/cursor-prompts.md) and cut one per file; the swords of set 4 are those of
set 5 turned half round. Loaded by `EternalWars.Godot.UI.GameCursors` with the hotspots from its `Definition` table; each image is placed so its
pointing part is on that hotspot (the arrow's, bow's and wand's tip in the top left corner, the hooves, boot and shovel at 7/8 down, the
swords' points one eighth in from the edges they point at, the others centred). A missing file leaves the system cursor in its place.
