# Resource icons

Painted resource icons, 256 × 256 with transparency, supplied for this project by the owner (2026-11-10). Loaded through
`EternalWars.Godot.UI.ResourceIcons`, which scales them to the size wanted; a missing file shows the resource's name instead.

| File | Used for |
|---|---|
| gold.png | Gold: the resource bar, the kingdom overview, the marketplace (and its buttons) |
| lumber.png / ore.png / crystal.png / mercury.png / sulfur.png | the other resources, in the same places |
| gold_pile.png | the treasury: the Kingdom (K) button |
