# Resource icons

Painted resource icons, 128 × 128 with transparency, supplied for this project by the owner, cut from an icon sheet (2026-11-16, replaced by a new sheet 2026-11-21; prompts
in `docs/content/prompts/icon-prompts.md`). Loaded through
`EternalWars.Godot.UI.ResourceIcons`, which scales them to the size wanted; a missing file shows the resource's name instead.

| File | Used for |
|---|---|
| gold.png | Gold: the kingdom overview, the marketplace (and its buttons), every cost and price on a button or in a line (town, tavern, map dwellings and services, adventure choices, surrender) |
| lumber.png / ore.png / crystal.png / mercury.png / sulfur.png | the other resources, in the same places and the resource bar |

The treasury (the Kingdom (K) button, the player's gold on hand in the resource bar and the tavern window's header) uses the
Treasury skill's chest, `../skills/estates.treasury.png`.
