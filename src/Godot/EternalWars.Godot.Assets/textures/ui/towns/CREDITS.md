# Town pictures

Painted town views (260 × 128, opaque), generated for this project by the owner (2026-11-26) as five sheets of four (prompts in
`docs/content/prompts/town-picture-prompts.md`, sheets T1–T5) and cut into one file per picture: each cell inside its gap, the
2.03:1 band kept from near its top (the landmark's tip stays, the foreground ground goes), scaled with Lanczos.

| File | Used for |
|---|---|
| town_<town type>.png | the town list's entry of a town with a fort, the ten town types |
| town_<town type>_village.png | the same for a town without a fort |
