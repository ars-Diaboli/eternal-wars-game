# Heraldry

Faction crests and charges, 128 × 128 with transparency, generated for this project by the owner (2026-11-18) from the "Heraldry" sheets
of [icon-prompts.md](../../../../../../docs/content/prompts/icon-prompts.md) (sets 23–28) and cut one figure per file. Loaded through
`EternalWars.Godot.UI.Heraldry`, which scales them to the size needed; a missing file leaves the faction's name alone.

| File | What |
|---|---|
| crest_&lt;town&gt;.png | the town type's crest (haven, sylvan, academy, necropolis, inferno, dungeon, stronghold, swamp-bestiary, conflux, dragon-utopia) |
| crest_group_&lt;group&gt;.png | the group's crest (dawn-covenant, ashen-court, unbound, firstborn) |
| charge_&lt;id&gt;.png | the same figure without the shield, engraved silver on transparency, for one-colour use (banners, map markers) |

Used: the crests before a town's name (town list, town screen, kingdom overview), on the hero screen's title for a roster hero, on the
tavern's hero cards, in the new-game screen's faction column, the leaderboard's faction column and the map editor's faction choices. The
group crests and the charges are not used yet.
