# Frames

The painted frames and panels of the UI, generated for this project by the owner (2026-11-24) from the "Frames and panels" prompts of
[ui-element-prompts.md](../../../../../../docs/content/prompts/ui-element-prompts.md), cropped to the element and scaled to their size on
screen. Loaded through `EternalWars.Godot.UI.UiFrames` as nine-slice boxes; a missing file leaves the flat look.

| File | What | Used |
|---|---|---|
| ui_frame_window.png | heavy bronze frame with riveted corner plates | screens, windows, the map's question and notice cards |
| ui_frame_overlay.png | thin bronze frame with square studs | the bottom row's parts over the map |
| ui_frame_tooltip.png | fine bronze line with corner studs | tooltips, the map's hover card |
| ui_frame_header.png | title plate with scrolled ends | a window's title |
| ui_frame_divider.png | bronze rod with a diamond at each end | dividers |
| ui_frame_status-bar.png | slate strip between rails, end caps | the status bar and the top bar |
| ui_frame_side-panel.png | tall column with a cast ornament at top and bottom | the HUD's column, the hero list |
| ui_frame_minimap.png | heavy frame with studded corners, open inside | the minimap |
