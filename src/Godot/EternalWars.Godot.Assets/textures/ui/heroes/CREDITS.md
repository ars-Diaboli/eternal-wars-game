# Hero portraits

Painted hero portraits with transparency (512 × 512, the face filling the cell, the shoulders at the bottom edge), generated for this
project by the owner (2026-11-22: Haven, Sylvan) as portrait sheets and cut into one file per hero (prompts in
`docs/content/prompts/hero-town-icon-prompts.md`). Specks and the faint fringe the background removal left around each figure were
cleared when cut; larger detached pieces (Ithiel's insects) stay. The game does not show them yet: the hero frames still show the
hero's name.

| File | Used for |
|---|---|
| icon_hero_haven.<hero id>.png | the twenty Haven heroes (sheets Warriors 1–4, Warriors 5–8, Mages 1–4, Mages 5–8, Campaign 1–4) |
| icon_hero_sylvan.<hero id>.png | the twenty Sylvan heroes (the same five sheets) |

Not drawn yet: the other factions.
