# Skill icons

Painted skill icons, 128 × 128 with transparency, generated for this project by the owner (2026-11-16) as icon sheets and cut into one
file per skill (prompts in `docs/content/icon-prompts.md`). Each file is named by its skill id (`offense.melee.png`). Loaded through
`EternalWars.Godot.UI.HeroIcons`; a skill without a file shows its text alone.

| Files | Used for |
|---|---|
| offense.\*, defense.\*, estates.\*, pathfinding.\*, tactics.\*, rage.\* | the hero screen's skill rows, the level-up and witch hut choices |

Not drawn yet: the war machine skills (`machines.*`) and the magic schools' skills (`magic.*`).
