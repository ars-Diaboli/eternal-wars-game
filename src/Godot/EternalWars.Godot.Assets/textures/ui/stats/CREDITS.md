# Hero stat icons

Painted stat icons, 128 × 128 with transparency, generated for this project by the owner (2026-11-16, replaced by a new sheet 2026-11-21; sheets 2 and 8 regenerated in pale satin aluminium 2026-11-26; sheet 34, the battle stack panel's, 2026-11-26) as an icon sheet and cut into one
file per stat (prompts in `docs/content/prompts/icon-prompts.md`). Loaded through `EternalWars.Godot.UI.HeroIcons`; a missing file shows the
stat's name instead.

| File | Used for |
|---|---|
| attack.png / defense.png / spell_power.png / knowledge.png | the hero screen's stats; attack to knowledge also the training choices; attack and defense also the battle stack panel's |
| mana.png / experience.png | the hero screen's mana and experience; mana also the battle side plate's |
| morale.png (banner) / luck.png (clover) | the hero card's morale and luck badges (sheet 8), the battle stack panel's |
| movement.png (winged boot) / sleep.png (closed eye, crescent moon) | sheet 8 |
| damage.png (spiked mace) / health.png (heart with a cross) / speed.png (horseshoe, speed lines) / initiative.png (pocket watch, lightning) / shots.png (quiver) | the battle stack panel's numbers (sheet 34) |
| native_terrain.png (pine on a hill) | the battle stack panel's native-terrain mark (sheet 34) |
