# Hero stat icons

Painted stat icons, 128 × 128 with transparency, generated for this project by the owner (2026-11-16, replaced by a new sheet 2026-11-21) as an icon sheet and cut into one
file per stat (prompts in `docs/content/prompts/icon-prompts.md`). Loaded through `EternalWars.Godot.UI.HeroIcons`; a missing file shows the
stat's name instead.

| File | Used for |
|---|---|
| attack.png / defense.png / spell_power.png / knowledge.png | the hero screen's stats; attack to knowledge also the training choices |
| mana.png / experience.png | the hero screen's mana and experience |
| morale.png (banner) / luck.png (clover) / movement.png (winged boot) / sleep.png (closed eye, crescent moon) | not used yet (sheet 8) |
