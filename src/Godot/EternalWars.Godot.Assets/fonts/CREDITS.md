# Fonts

Two pairings for the UI (the town screen plan, step 1; ADR-294), each a heading face and a body face under the SIL Open Font License 1.1.
The licence travels with each family (`OFL-<family>.txt`). Downloaded from the Google Fonts repository (`github.com/google/fonts`,
`ofl/<family>/`) on 2026-11-22.

| File | Family | Pairing | Authors |
|---|---|---|---|
| Cinzel-Variable.ttf | Cinzel (variable weight) | A: headings | The Cinzel Project Authors (github.com/NDISCOVER/Cinzel) |
| AlegreyaSans-Regular.ttf, AlegreyaSans-Bold.ttf | Alegreya Sans | A: body | The Alegreya Sans Project Authors (github.com/huertatipografica/Alegreya-Sans) |
| MarcellusSC-Regular.ttf | Marcellus SC | B: headings | Brian J. Bonislawsky, Astigmatic (AOETI) |
| FiraSans-Regular.ttf, FiraSans-SemiBold.ttf | Fira Sans | B: body | The Mozilla Foundation and Telefonica S.A. |
